# House Price Prediction using Machine Learning

## Project Overview
This project predicts house prices based on area using Machine Learning.
It is a beginner-level supervised learning project implemented in Python.

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

## Problem Statement
To predict house prices based on house area (square feet).

## Machine Learning Approach
- Supervised Learning
- Linear Regression Algorithm

## Sample Input
Area: 1000 sq ft

## Output
Predicted House Price: 4000000

## Conclusion
This project demonstrates regression-based prediction using Python and Machine Learning.
